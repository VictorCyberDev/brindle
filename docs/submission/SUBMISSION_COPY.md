# Submission copy

## One line

Brindle Recovery finds exactly what a changed fact touched, recovers only that, preserves everything else, and proves it.

## Short description (about 50 words)

When a fact your AI agents relied on turns out to be wrong, Brindle traces every affected decision, re-decides each with the corrected fact, recovers only what would change through a fixed capability registry, never rolls back what cannot be undone, and issues an independently verified Recovery Proof.

## What we built

- A recovery engine: bitemporal truth, consequence graph, counterfactual materiality, registry-bound recovery, fresh independent verification, Recovery Receipt.
- Recovery Memory (H-MEM): verified recoveries are remembered and consulted before planning. Advisory only.
- A private-beta product: sign-up, workspaces, roles, trust modes, evidence API with hashed keys, incident review, approval, shareable proof.
- A guided tour and Demo Workspace, clearly labeled DEMO DATA.

## What is honestly not done

- Connectors that execute recovery in a customer's own systems.
- LIVE sponsor acceptance for Zetaris and Meterless Nightshift is BLOCKED; it is not claimed.
- No customers, no certifications, no billing.
